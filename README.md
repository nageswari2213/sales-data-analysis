# Sales Data Analysis

Excel-based analysis of sales data to find category, regional, and sales representative trends.

**Tools:** Microsoft Excel (Pivot Tables, Charts, Slicers)

## What I Did
- Cleaned the sales data
- Used pivot tables to analyze sales by region, category, and sales representative
- Created charts and slicers to compare the results

## Key Insights
- West had the highest sales (28,275)
- Electronics was the top category (62,232 of 91,128 total sales)
- Office Supplies had the lowest sales (5,436)
