# Sales Data Analysis

Excel-based analysis of sales data to find product, monthly, and regional trends.

**Tools:** Microsoft Excel (Pivot Tables, Charts)

## What I Did
- Cleaned the sales data
- Used pivot tables to analyze sales by product, month, and region
- Created charts to show the trends

## Key Insights
- Product A had the highest sales
- Sales were highest in December
